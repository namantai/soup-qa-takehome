# BUG-001 - Train dry-run accepts a dropout probability above one

Evidence links are public derivatives; unchanged originals are supplied separately. See [evidence policy](../evidence/README.md).

## Environment

Soup CLI 0.77.2; Python 3.11.16; Arch Linux x86-64. [Original environment manifest](../evidence/derived/logs/stage-3/20261110T091544Z-pytest-56cb4d/manifest.json).

## Preconditions

Complete the base installation in [README](../README.md). The retained fixture includes the 20-row synthetic dataset; no GPU or model download is required. The [positive control](../evidence/derived/logs/stage-3/20261110T091544Z-pytest-56cb4d/001-positive-control/) passed before negative tests.

## Steps to reproduce / minimal example

1. Inspect the [complete input](../evidence/derived/logs/stage-3/20261110T091544Z-pytest-56cb4d/123-range-dropout/input.yaml). The single invalid setting is `training.lora.dropout: 1.1`; other fields retain the valid baseline.
2. From the repository root, run:

   ```sh
   .venv/bin/python -m scripts.replay_case evidence/derived/logs/stage-3/20261110T091544Z-pytest-56cb4d/123-range-dropout --repeat 1
   ```

The helper creates fresh evidence and calls `soup train --config input.yaml --dry-run`. Its expected rejection fails, so the helper returns 1 while Soup returns 0. It never overwrites the original case.

## Expected

Reject with train config-error exit 1, name `training.lora.dropout`, and do not announce readiness. Dropout is a probability, so 1.1 is outside its domain. [Train help](../evidence/derived/logs/stage-4/preparation/train-help/stdout.txt) promises config/data validation; the [original oracle](../evidence/derived/logs/stage-3/20261110T091544Z-pytest-56cb4d/123-range-dropout/case.json) records the basis.

## Actual

Soup exits **0**, reports 18 train / 2 validation rows and prints `Config valid. Ready to train!`. There is no dropout diagnostic; stderr is empty.

## Severity: Low

Misleading early validation gives false setup confidence and can cause rework. Downstream failure timing, GPU cost and incorrect trained output were not measured.

The student personally executed the prepared helper and reviewed terminal output; the script and internal analysis were AI-assisted. No separate outer shell transcript/helper exit capture was supplied for that manual run. Original child-process evidence is present. These reproductions are not an estimate of frequency in normal use.

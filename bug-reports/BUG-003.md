# BUG-003 - Preprocess saves a cache without warning that prompt_strategy is unsupported

Evidence links are public derivatives; unchanged originals are supplied separately. See [evidence policy](../evidence/README.md).

## Environment

Soup CLI 0.77.2; Python 3.11.16; Arch Linux x86-64. Separate CPU libraries: transformers 5.17.0, tokenizers 0.23.3, Jinja2 3.1.6 and datasets 4.0.0. [Original command and environment](../evidence/derived/logs/stage-5/20261111T065954Z-preprocess-574245/configured/invocation.json).

## Preconditions

Complete the full CPU setup in [README](../README.md), including public artifact restoration. Use the saved SmolLM2 tokenizer under `runs/returned/stage4-20261111T063626Z/runs/repro/run-a` and libraries under `runs/stage5-tokenizer-deps`. No GPU or model-weight loading is required.

## Steps to reproduce / minimal example

1. Inspect the one-row [input](../evidence/derived/logs/stage-5/20261111T065954Z-preprocess-574245/data.jsonl): uppercase `apple` → `APPLE`.
2. Compare [baseline](../evidence/derived/logs/stage-5/20261111T065954Z-preprocess-574245/baseline.yaml) and [configured YAML](../evidence/derived/logs/stage-5/20261111T065954Z-preprocess-574245/configured.yaml). Only `data.prompt_strategy: scripts.stage5_prompt_strategy:add_marker` differs. The [pure callback](../scripts/stage5_prompt_strategy.py) prepends `QA_REQUIRED_PREFIX` to the user message.
3. From the repository root, run:

   ```sh
   env PYTHONPATH="$PWD/runs/stage5-tokenizer-deps:$PWD" .venv/bin/python -m scripts.probe_preprocess
   ```

The probe checks normal SFT formatting, then runs real baseline/configured `soup data preprocess CONFIG --output NEW_CACHE --yes` calls in new directories. It inspects the saved Arrow rows. The helper returns 1 for the missing marker; both Soup calls return 0.

## Expected

Apply the requested transform or explicitly refuse/explain the unsupported option before presenting the cache as suitable. A clear warning would remove the silent feedback failure; this report does not require adding transform support. The [schema](../evidence/derived/logs/stage-5/inspection/source/config/schema.py) describes a per-row SFT transform and acknowledges the preprocessing limitation in a later pre-tokenized validation guard. The [normal-format control](../evidence/derived/logs/stage-5/20261111T065954Z-preprocess-574245/normal-sft-control.json) proves the callback/tokenizer work.

## Actual

Both Soup calls exit **0** and write one row. Configured preprocessing recommends using the cache without warning about `prompt_strategy`. The baseline and configured rows have identical IDs/labels and the same cache key within each pair. The configured decoded row lacks the marker; normal SFT includes it. Stderr warnings concern missing PyTorch and generation markers, not the omitted transform.

## Severity: Low

This is a feedback/early-validation defect around an unsupported combination. It misleads the user about the saved cache, but the later training guard blocks the unchanged configuration. Incorrect GPU training is not demonstrated.

Original child-command evidence exists, but no separate outer shell transcript/helper exit capture was supplied. No manual recalculation of all tokens is claimed.
